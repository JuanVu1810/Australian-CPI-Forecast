# Reports

[![content: AI-generated](../book/australian_cpi_forecasting/_static/badges/ai-generated.svg)](https://juanvu1810.github.io/CPI-Forecast/intro.html#ai-acknowledgement)

The markdown notes in this folder were drafted by AI. Unlike the Jupyter Book pages, I haven't
marked them as human-reviewed. The decision notes carry the tag at the top.

The CSV files are results, not AI-written text: the project's code computes them from the data.
That code was itself written with Codex and Claude Code, as the AI acknowledgement explains. Reports
that the code regenerates (for example `rba_classifier_evaluation.md`) can't carry the tag, because
rerunning the code would overwrite it.

The book reads its numbers from these files. The [AI acknowledgement](https://juanvu1810.github.io/CPI-Forecast/intro.html#ai-acknowledgement) explains what the
tags mean.
